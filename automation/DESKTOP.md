# 한자리 — AI 오케스트레이터

브라우저와 웹 서버 없이 독립 창에서 실행한다. Python에 포함된 Tk GUI가 기존 Backend를 직접 호출하고, 실행 버튼을 누르면 workspace.py를 자식 프로세스로 실행한다. 웹 대시보드는 선택적으로 남아 있지만 데스크톱 앱 사용에 필요하지 않다.

## 시작하기

바탕화면의 **한자리 스튜디오** 바로가기를 더블클릭한다. Python 콘솔 창 없이 앱이 열린다. 앱 시작과 상태 조회는 AI 작업을 시작하지 않는다.

직접 실행하려면 저장소 루트에서:

```powershell
python .\automation\desktop.py
```

현재 PC의 Python 3.13/Tk 8.6을 사용한다. 추가 패키지 설치는 없다. 이 버전은 Python이 설치된 현재 PC용 앱이며 Python을 포함한 독립 실행 파일(.exe) 배포판은 아니다. 같은 설정·모드는 한 창만 실행할 수 있다.

## 화면과 조작

- 진행 현황: 현재 단계, 승인 여부, Claude 5시간·7일 사용률과 마지막 갱신 시각.
- 기획과 결정: 전체 기획안과 승인 대상 해시. 확인란을 선택해야 승인할 수 있으며 개발은 이후 별도로 실행한다.
- 기능별 업무: 기능을 선택하면 요구사항·인수 기준·의존 업무·제외 범위를 표시한다.
- 리뷰와 검증: 저장된 검토 결과, 테스트 근거와 관련 파일 목록. 실제 코드는 기존 에디터/PR에서 검토한다.
- 활동 기록: 프로젝트의 변경·승인·실행 기록.
- 요청·복구: 요청 처리 상태와 로컬 로그 경로, 실패 원인 해결 후 재시도 예산 복구.

실행 중에는 중단 요청과 아이디어 기록만 허용한다. 중단은 현재 단계가 끝난 뒤 적용되며 강제 종료가 아니다. 작업이 끝난 뒤 수정 요청으로 요구사항을 새 기획 버전에 반영한다. 현재 기능 리뷰 완료는 사용자 수락을 기록하며 PR을 병합하지 않는다.

## 종료와 실행 환경

실행 중 창 닫기를 누르면 창을 유지하고 중단 절차를 안내한다. 중단 요청 후 현재 단계와 요청 처리가 끝나면 닫는다. 창이 닫혀도 기획·개발 상태는 기존 파일에 남지만 앱에서 보낸 요청 목록은 재시작 시 초기화된다.

바로가기로 실행한 앱은 Windows 사용자 환경변수를 상속한다. **특정 PowerShell 창에만 설정한 DB 환경변수는 상속하지 않는다.** 그런 환경으로 개발하려면 필요한 환경변수를 설정한 동일 터미널에서 `python .\automation\desktop.py`로 실행한다. 비밀번호를 코드·바로가기 인수·Notion에 저장하지 않는다. 기존 제어기가 DB 준비와 Claude 사용량 제한을 검사한다.

설정은 기존 automation/config.json을 사용한다. 상태는 3초마다 파일에서 읽으며 모델·Notion API를 호출하지 않는다. 데스크톱/웹/CLI를 동시에 사용해 명령을 중복 전달하지 않는다. 기존 CLI의 공유 잠금과 승인 검사가 마지막 실행 경계를 보호한다.

새 프로젝트 등록은 현재 workspace.py register를 사용한다. 새 저장소와 폴더·Notion 연결을 등록하면 앱의 프로젝트 선택 목록에 표시된다. 등록 전용 GUI, 설치 마법사, 트레이 상주, 자동 업데이트는 이 버전에 포함되지 않는다.

## 파일과 검증

- desktop.py: 네이티브 화면, 사람의 결정 창, 중복 창 방지, 종료 보호.
- dashboard.py: 웹 화면과 공유하는 명령·상태 연결부. 데스크톱은 HTTP 서버를 시작하지 않는다.
- desktop_assets/hanjari.ico: 앱과 바로가기 아이콘.
- test_desktop.py: 승인/실행 제한, 정확한 승인 해시, 종료 보호, 자동 실행 없음, 텍스트 선택 보존 검증.

```powershell
python -m unittest discover -s automation -p "test*.py"
```


## UI/UX와 이름 (2026-10-31)

한자리(HanJari)는 자동화 오케스트레이터의 이름이다. 기존 영화 제품은 프로젝트 선택과 작업 화면에서 「영화 예매 MVP」로 구분한다. 이는 표시 이름이며 저장소·Notion 연결 ID·승인 대상 해시·기존 기획 문서 제목을 바꾸지 않는다. 영화 제품의 정식 이름은 별도로 정한다.

검은색 배경과 민트색 강조를 사용한다. 진행 현황의 우선 버튼은 현재 단계에 따라 기획 검토·코드 리뷰·처리 현황·다음 작업 실행으로 바뀐다. 검토 버튼은 문서를 열며 승인을 대신하지 않는다.

문서의 제목·강조·코드를 읽기 쉽게 표시하고 기획안 검색(Ctrl+F, Enter로 다음 결과), 기능 목록 검색, F5 상태 새로고침을 제공한다. 비활성 버튼에 마우스를 올리면 사용 불가 사유가 표시된다. 사용량을 읽지 못하면 확인 필요로 표시하며 0%로 간주하지 않는다.

버튼·안내 카드·사용량 카드·선택 메뉴에 라운드를 적용했다. 키보드 포커스와 호버 상태를 표시하고, 작은 창에서는 진행 현황 전체를 스크롤해 읽을 수 있다. 네이티브 UI/승인 보호 테스트 11개와 전체 125개 회귀 테스트를 확인했다.


## Claude Design 목업 반영 (2026-11-02)

화면을 목업 기준의 5개 메뉴와 공통 상태 표시, 사이드바 사용량, 문서/승인 패널 구조로 개편했다. Ctrl+1~5로 이동하며 작은 창에서는 문서 목차를 접는다. 새 기획 버전은 자동으로 승인하지 않고 명시적 재검토를 기다린다. 상세 반영 범위와 제약은 [디자인 반영 안내](DESIGN-INTEGRATION.md)를 참고한다.

## 데스크톱에서 프로젝트 추가 (2026-11-02)

왼쪽 프로젝트 선택 아래 **+ 프로젝트 추가**를 누른다. 이름, 고유 ID, GitHub origin이 설정된 로컬 저장소 폴더, Notion 결과 페이지, 아이디어를 입력한다. Notion 페이지는 링크 또는 UUID를 받는다. 원본 페이지, 업무 접두사, 기존 테스트 기준 JSON도 지정할 수 있다. 기존 테스트가 있는 저장소는 회귀 기준 JSON이 필요하다.

기존 CLI 등록 검증과 등록 잠금을 그대로 사용한다. 중복 ID·저장소 등록, 원본과 결과가 동일한 Notion 페이지는 거부한다. 성공하면 새 프로젝트가 선택되지만 AI는 실행하지 않는다. 사용자가 다음 작업 실행을 눌러 기획을 시작하고 기존 승인 절차를 따른다.

이 버튼은 저장소·GitHub origin·Notion 페이지를 생성하지 않는다. 준비된 자원을 연결한다. Notion 접근 권한은 실행·동기화 시 확인한다. 현재 개발 실행 지원은 Java/Spring Boot/Maven/MySQL이며, 다른 기술 스택 실행기는 후속 범위다.

## 목업 그대로의 화면 — Edge 앱 창 (2026-11-02)

Tk로는 목업(`HanJari App.dc.html`)의 글꼴·그림자·레이아웃을 재현할 수 없어, 같은 화면을 HTML/CSS로 구현하고 Edge 앱 모드 창(주소창 없는 독립 창)으로 띄운다. 추가 Python 패키지는 없다.

- 실행: 바탕화면 **한자리 스튜디오** 또는 `python .\automation\studio.py`. 바로가기는 `install-studio.ps1`이 `studio.py`로 바꾼다(기존 대상이 desktop.py/studio.py일 때만 교체). 이전 Tk 앱은 `python .\automation\desktop.py`로 계속 실행할 수 있다.
- 구조: `studio.py`가 `dashboard.py`의 서버를 127.0.0.1의 임의 포트로 띄우고 `msedge --app`을 전용 프로필(`.runtime-studio/edge-profile`)로 연다. 창을 닫으면 서버도 종료되며, 진행 중인 요청이 있으면 끝날 때까지 기다린 뒤 종료한다. Tk 앱과 같은 중복 실행 잠금을 쓴다.
- 화면: `studio_assets/`(index.html·style.css·app.js). 목업의 색·간격·글꼴(Pretendard, JetBrains Mono — OFL, `studio_assets/fonts`)을 그대로 쓰고, 값은 모두 `/api/state`의 실제 상태에서 가져온다. 데모 데이터와 데모 상태 전환 패널은 없다.
- 명령: 기존 `/api/action` 허용 목록(workspace.py)만 사용한다. 추가 경로는 프로젝트 등록(`/api/register`, 기존 등록 검증 재사용), 폴더·JSON 선택 창(`/api/pick`), 파일 열기(`/api/open`, 프로젝트 폴더 안 파일과 앱 로그만, VS Code 또는 메모장으로 열고 실행하지 않음)이며 모두 세션 토큰이 필요하다.
- 목업과 다른 점: 기획 버전은 `r{리비전}`으로 표시한다. 결정 선택지 라디오, 파일별 +/- 줄 수, 인수 기준별 테스트 매핑, GitHub PR 링크는 실제 데이터가 없어 표시하지 않는다. 리뷰의 「수정 요청」은 기존 revise(새 기획 버전) 경로로, 「보류」는 아이디어 기록으로 남긴다. 창 제목 표시줄은 Edge 기본 제목 표시줄을 쓴다.
- 검증: `test_studio.py`(정적 파일 허용 목록, 토큰, 파일 열기 범위) 포함 146개 회귀 테스트.
